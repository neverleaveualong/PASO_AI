# PASO AI PR 규칙 (Pull Request Rule)

모든 Pull Request(PR)는 코드 리뷰와 변경 이력 파악이 쉽도록 **개요 - 요약 - 상세** 구분선 포맷과 **4자리 버전(`0.0.0.x`)** 표기를 필수로 작성합니다.

---

## 1. PR 제목 포맷

```text
[<type>] <PR 핵심 제목> (v0.0.0.x)
```

### 예시
* `[docs] 초기 모노레포 디렉토리 구성 및 형상관리 규칙 정의 (v0.0.0.1)`
* `[feat] PASO Lens 선행특허 유사도 검색 API 구현 (v0.0.0.2)`
* `[fix] 명세서 에디터 도면 부호 하이라이팅 오류 수정 (v0.0.0.3)`

---

## 2. PR 본문 템플릿 구조

PR 작성 시 아래의 구분선(`---`) 구조를 유지하여 작성합니다. (`.github/PULL_REQUEST_TEMPLATE.md`에 자동 적용되어 있습니다.)

```markdown
## 개요
<!-- 이번 PR을 진행하게 된 배경과 목적을 간단히 작성합니다. -->
- 

---

## 요약
<!-- 핵심 변경 사항을 한눈에 파악할 수 있도록 불릿 포인트로 요약합니다. -->
- 

---

## 상세
<!-- 파일별/모듈별 구체적인 변경 내용, 기술적 의사결정, 아키텍처 변경 등을 상세히 작성합니다. -->
### 1. 주요 변경 내역
- 

### 2. 참고 및 특이사항
- 

---

## 버전 정보
- **이전 버전**: `0.0.0.0`
- **현재 버전**: `0.0.0.1`

---

## 체크리스트
- [ ] 커밋 메시지 규칙(`feat : `, `docs : `, `fix : ` 등)을 준수했나요?
- [ ] 루트 `VERSION` 파일의 버전을 업데이트했나요?
- [ ] 빌드 및 로컬 테스트가 정상 동작하나요?
```
