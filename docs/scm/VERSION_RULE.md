# PASO AI 버전 관리 규칙 (Version Control Rule)

PASO AI는 모든 수정 사항을 세밀하게 추적하기 위해 **4자리 버전 체계 (`0.0.0.0`)**를 사용합니다.

---

## 1. 버전 구조 (`MAJOR.MINOR.PATCH.REVISION`)

```text
0 . 0 . 0 . 0
│   │   │   └── 4번째 자리 (Revision / Build): 매 수정(커밋/PR)마다 +1 증가 (0.0.0.1 -> 0.0.0.2 ...)
│   │   └────── 3번째 자리 (Patch): 버그 픽스 배포 또는 소규모 기능 단위 완료 시 +1 증가
│   └────────── 2번째 자리 (Minor): 주요 모듈(PASO Lens, PASO Docs 등)의 기능 출시 시 +1 증가
└────────────── 1번째 자리 (Major): 정식 상용 릴리즈 또는 대규모 아키텍처 개편 시 +1 증가
```

---

## 2. 버전 업데이트 규칙

1. **초기 기준 버전**: `0.0.0.0` (현재 `0.0.0.1`)
2. **버전 업데이트 대상 (`feat`, `fix`, `refactor` 등 코드/기능 변경)**:
   - 실제 소스 코드(`frontend`, `backend`) 및 기능/버그 수정 시마다 루트 디렉토리의 [`VERSION`](../../VERSION) 파일 4번째 자리 숫자를 `1` 올립니다.
   - 예: `0.0.0.1` -> `0.0.0.2` -> `0.0.0.3`
3. **버전 업데이트 제외 대상 (`docs`)**:
   - 단순 문서(`docs/`, `README.md`) 추가 및 수정 작업은 버전을 올리지 않고 현재 버전을 유지합니다.
4. 상위 자리가 올라갈 때 하위 자리는 `0`으로 초기화합니다.
   - 예: `0.0.0.15`에서 패치 마일스톤 달성 시 -> `0.0.1.0`
